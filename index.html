PSBT Generator

Builds an unsigned PSBT for Sparrow Wallet, valid on exactly one chain: Bitcoin (SHA256d) or the BLAKE2b fork.

Chain

Any Esplora / mempool-compatible API. Reset automatically when the chain changes.

Input UTXOs

Previous transaction ID and output number, as txid:vout. Value, script type and spent status are looked up on the selected chain.

The Bitcoin address to pay. Mainnet only: 1…, 3…, bc1q… or bc1p… (identical on both chains).

Whole satoshis. 100,000,000 sats = 1 BTC.

Your own address. Receives the inputs minus the payment and the fee.
